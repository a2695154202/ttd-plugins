# 企业微信通知 · TgtoDrive 插件

为 **TgtoDrive** 补上企业微信（WeCom）通知能力：填写企业自建应用的凭据后，即可把任意文本、markdown 或文本卡片推送到成员、部门、标签或全体可见成员。

按企业微信官方接口实现：`GET /cgi-bin/gettoken` 与 `POST /cgi-bin/message/send`
（参考 <https://developer.work.weixin.qq.com/document>）。

- **插件 id**：`wecom-notify`
- **版本**：`1.0.1`
- **作者**：`a2695154202`
- **入口**：`plugin.py`
- **超时**：120 秒
- **依赖**：仅使用 Python 标准库 + 容器已安装的 `requests`（不可用时自动回退 `urllib`）。**不安装任何依赖。**
- **许可证**：GPL-3.0（与本仓库一致）

> ⚠️ **插件不含任何内置凭据。** 企业 ID、AgentId、Secret、Token、EncodingAESKey、白名单全部由你填写，代码里不存在示例值。

## 一、它能做什么

| 功能（`func`） | 说明 |
| --- | --- |
| 发送消息（`send`） | 按当前表单的收件人、消息类型与正文发送；超长正文可自动分段 |
| **发送测试消息（`test`）** | 检查「文本消息内容」与「卡片消息内容」两个输入框：都有内容就依次发送（**间隔 3 秒**，共两条通知），只有一个就只发一条，都为空则报错。界面右上角有独立按钮 |
| 检查配置（`config`） | 逐项校验必填与格式，并真实获取一次 `access_token`，给出剩余有效期 |
| 查询应用可见范围成员（`users`） | 拉取部门与成员列表，用于确定要填的 UserID / 部门 ID |
| 查看发送历史（`history`） | 本地记录每次发送的时间、类型、收件人、结果与 msgid |
| **查看调用方法（`docs`）** | 输出「被其他插件调用」的参数表、示例与在线文档链接，界面右上角有独立按钮 |

支持的消息类型：

- **文本 text** —— 正文上限 2048 字节，支持换行与 `<a href="...">文字</a>` 链接；
- **markdown** —— 企业微信 markdown 子集（标题、加粗、引用、行内代码、`<font color="info|warning|comment">` 彩色字、链接），排版更适合通知；
- **文本卡片 textcard** —— 带标题与跳转按钮，需要同时填写「卡片标题」和「卡片跳转链接」；
- **卡片通知 template_card** —— **带图卡片**：大图 + 标题 + 键值列表，参数见 [五、卡片通知](#五卡片通知带图)。

## 二、准备：企业微信后台要做什么

1. 登录 [企业微信管理后台](https://work.weixin.qq.com/)。
2. **我的企业 → 企业信息**：复制「企业 ID」（`corpid`，通常以 `ww` 开头）。
3. **应用管理 → 自建应用 → 创建应用**（或用已有应用），进入应用详情：
   - 复制 **AgentId**（纯数字）；
   - 复制 **Secret**（点「查看」，只显示一次，请及时保存）；
   - 把需要接收消息的成员 / 部门加入 **可见范围**。
4. **企业可信 IP**（关键）：
   - 2022 年 6 月 28 日之后**新创建**的自建应用，必须把服务器出口 IP 加入应用详情里的「企业可信IP」，否则调用接口会返回 `60020`；
   - 如果服务器出口 IP 不固定，可在应用详情填写一个**转发代理地址**，然后在插件的「代理地址」里填它 —— 请求会发往「代理地址 + `/cgi-bin/...`」，由代理的固定 IP 调用企业微信接口。

> 拿不到出口 IP 时有个小技巧：先随便发一次（或点「检查配置」），报错信息里的 `60020` 会带上实际调用的 IP，插件会把它直接显示在结果页。

## 三、配置字段说明

界面分四个页签（发送消息 / 卡片通知 / 应用配置 / 回调与高级），右上角固定三个按钮（「发送消息」「发送测试消息」「查看调用方法」）。

### 应用配置

| 字段 | 说明 |
| --- | --- |
| 通知渠道名称 | 只用于界面显示与测试消息前缀，随意填写（例如 `WX`） |
| 企业 ID | 必填，企业微信的 `corpid` |
| 应用 AgentId | 必填，纯数字 |
| 应用 Secret | 必填，自建应用的 Secret |
| 代理地址 | 默认 `https://qyapi.weixin.qq.com`；使用转发代理时改写为代理地址 |
| 网络代理 | 默认**「不使用代理（直连）」**。转发代理地址通常是「只允许特定地区访问」的服务，若插件跟随容器的 `HTTP_PROXY` / `HTTPS_PROXY`，请求会被送去代理而直接连不通（表现为 `SSLError ... UNEXPECTED_EOF_WHILE_READING`）。只有容器必须经代理才能出网时，才改成「跟随容器环境变量代理」 |

### 发送消息

| 字段 | 说明 |
| --- | --- |
| 执行功能 | `send` / `test` / `config` / `users` / `history` |
| 消息类型 | `text` / `markdown` / `textcard` |
| 接收成员 | UserID，多个用 `\|` 分隔，最多 1000 个；`@all` 表示全体可见成员 |
| 接收部门 / 标签 | 部门 ID / 标签 ID，多个用 `\|` 分隔；`touser` 为 `@all` 时被忽略 |
| 保密消息 | 对应接口 `safe=1`：不可分享且带水印 |
| 卡片标题 / 跳转链接 | 仅 `textcard` 需要 |
| 消息内容 | 正文；`test` 功能会忽略它 |

### 回调与高级

| 字段 | 说明 |
| --- | --- |
| 回调 Token | 自建应用「接收消息」配置里的 Token |
| EncodingAESKey | 同上，43 位 Base64 |
| 管理员白名单 | 成员 ID 列表；当「成员 / 部门 / 标签」都为空时，作为兜底收件人 |
| 超长消息自动分段 | 超过 2048 字节时按行边界切成多条依次发送并标注段落序号 |
| 历史记录保留天数 | 本地历史保留时长 |
| TgtoDrive 地址 / OpenAPI 令牌 | 可选；企业 ID 或 Secret 留空时，插件会尝试从 TgtoDrive 已保存的项目设置里读取微信渠道配置作为兜底 |

> **关于 Token / EncodingAESKey**：它们用于企业微信**推送消息给你**时的签名与解密。插件是一次性执行、无常驻进程，收不到回调，因此这两项仅做**配置留档与格式校验**（不对格式会在日志里提示），**不影响消息发送**。

### 收件人优先级

```
接收成员 / 部门 / 标签  →  管理员白名单  →  @all（全体可见成员）
```

## 四、发送消息

「发送消息」页签有**两个内容输入框**（都预置了示例内容，可直接点按钮试）：

| 输入框 | 用途 |
| --- | --- |
| **文本消息内容** | 「发送消息」按钮按「消息类型」发送本框内容（`text` / `markdown` / `textcard`） |
| **卡片消息内容** | 卡片通知的内容：每行一条「键=值」形成键值列表（最多 6 条）；整段不是键值格式时作为卡片正文。支持多行 |

两种发送方式：

- 点右上角 **「发送消息」**：按「消息类型」发送「文本消息内容」（消息类型选卡片通知时发送「卡片消息内容」）。
- 点右上角 **「发送测试消息」**：先检查两个输入框 ——
  - **两个都有内容** → 先发文本，**间隔 3 秒**再发卡片，你会收到**两条**通知；
  - **只有一个有内容** → 只发那一条；
  - **都为空** → 报错提示至少填写一个。

超长正文（> 2048 字节）会自动分段，每段末尾标注 `（第 x/y 段）`；关闭「超长消息自动分段」时只发第一段并在日志中提示。

## 五、卡片通知（带图）

把「消息类型」选为 **卡片通知 template_card**，然后到「卡片通知」页签填写卡片参数。
卡片是单条消息，不做分段；`text_notice` 的效果是「大图 + 标题 + 键值列表」。

| 字段 | 说明 |
| --- | --- |
| 卡片类型 | `text_notice`（默认，大图+键值列表）/ `news_notice`（图文展示型） |
| 卡片图片 | 卡片主图。可填 **http(s) 链接**、**内网地址**（如 `http://192.168.x.x/...`）或**容器内本地图片路径** —— 后两种企业微信都取不到，插件会自动下载并调 `media/uploadimg` 换取企业微信可用的图片 URL。建议 1068×455、JPG/PNG、≤2 MB |
| 卡片来源名称 | 左上角小字，例如 `站点 1PTBA 消息`（≤20 字） |
| 来源图标链接 | 来源名称左边的小图标（可留空） |
| 卡片副标题 | 标题下方一行说明（≤30 字） |
| 卡片消息内容 | 在「发送消息」页签填写：每行一条「键=值」，**最多 6 条**（键 ≤5 字、值 ≤30 字）；整段非键值格式时作为卡片正文 |
| 卡片图片比例 | 1.3–2.25，默认 2.25（宽图） |
| 卡片标题 / 卡片跳转链接 | 复用「发送消息」页签的「卡片标题」与「卡片跳转链接」 |

键值列表的写法（`=`、`:`、`：`、`|` 都能分隔）：

```text
时间=2026-10-13 18:04:48
季集=S01E15 第 15 集
分类=日番
评分=8.5/10
```

几条硬限制（企业微信侧，插件会主动截断并在日志中说明，避免静默丢字）：

- 键值列表 **最多 6 条**，超出部分丢弃；
- 键 ≤5 字、值 ≤30 字 —— 这也是为什么长剧情会被截断；
- 模板卡片必须有 `card_action`，即「卡片跳转链接」；留空时会回退到企业微信官网并在日志中提示；
- `news_notice` 必须有卡片图片，没有图片时会自动改用 `text_notice`；
- 卡片不支持「保密消息」。

## 六、被其他插件调用

本插件可以作为**企业微信通知出口**被其他插件调用，无需重复实现企业微信接口：

```python
import os, requests

base = os.environ.get("TGTO_OPENAPI_BASE_URL", "http://127.0.0.1:12366").rstrip("/")
token = os.environ["TGTO_OPENAPI_TOKEN"]

requests.post(
    base + "/api/toolbox/plugins/wecom-notify/run",
    headers={"Authorization": "Bearer " + token},
    json={"params": {
        "func": "send",
        "msgtype": "template_card",
        "touser": "@all",
        "title": "新入库剧集：示例标题",
        "card_source": "站点 1PTBA 消息",
        "card_image": "https://example.com/cover.jpg",
        "card_content": "时间=2026-10-13 18:04\n分类=日番",
        "url": "https://example.com/detail",
    }},
    timeout=(5, 30),
)
```

- `params` 里只需放本次变化的字段，其余沿用用户已保存的配置（凭据不必传、也拿不到）；
- **不要传 `save_settings: true`**，否则会把调用参数写进用户的插件设置；
- 完整参数表、返回值结构、结果轮询、错误处理与更多场景：
  **[CALLING.md](CALLING.md)**（插件界面点「查看调用方法」也能直接拿到链接）。

## 七、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `60020` IP 不在可信名单 | 把报错里给出的出口 IP 加入应用「企业可信IP」（约 1 分钟生效），或在「代理地址」填转发代理 |
| `SSLError` / `UNEXPECTED_EOF_WHILE_READING`，或 `Max retries exceeded` | 「代理地址」是只允许特定地区访问的转发服务，而请求走了容器代理（`HTTP_PROXY` / `HTTPS_PROXY`） | 把「网络代理」保持为**「不使用代理（直连）」**。网络类失败时结果页会自动给出 **DNS → TCP → TLS** 三层自检结论，直接指出卡在哪一层 |
| `40001` / `40013` | Secret 或企业 ID 不正确（Secret 重置过需重新复制） |
| `42001` / `40014` | access_token 过期；插件会自动清缓存重取一次 |
| `60011` / `82001` | 接收者不在应用可见范围内，或 UserID / 部门 ID 写错 |
| `45009` | 触发频率限制：每应用每天有人次上限，单成员每分钟不超过 30 条 |
| 收到消息但姓名显示为空 | 部分应用类型下成员姓名不返回，属企业微信侧策略，不影响发送 |

## 八、定时执行

在「实用工具 → 我的插件 → 定时执行」新建计划，选择本插件：

| 项目 | 建议值 |
| --- | --- |
| cron | `0 9 * * *`（每天 09:00，北京时间 Asia/Shanghai） |
| 运行参数 | `func=send`，填好收件人与内容 |
| timeout | 插件已声明 120 秒 |

插件内部不含任何定时循环，也不会 `sleep` 等下一次执行。

## 九、安装与使用

### 从插件市场安装

在 TgtoDrive「实用工具 → 我的插件 → 插件市场」添加仓库 `a2695154202/ttd-plugins` 为来源（分支 `main`，目录路径 `plugins.json`），刷新后选择本插件安装。

### 手动导入

导入 **打包产物**，不要导入源码目录里的 `plugin.py`：

| 文件 | 来源 |
| --- | --- |
| `wecom-notify.py`（单文件，推荐） | 仓库 [Releases](https://github.com/a2695154202/ttd-plugins/releases) 附件，或仓库内 [`dist/wecom-notify.py`](../../dist/wecom-notify.py) |
| `wecom-notify.zip`（插件包） | 仓库 [Releases](https://github.com/a2695154202/ttd-plugins/releases) 附件 |

> ⚠️ `plugins/wecom-notify/plugin.py` 是插件包内入口，清单在同目录 `plugin.json` 里，单独导入会报「Python 单文件必须在顶层定义唯一的 PLUGIN_MANIFEST 常量字典」。

### 本地构建

```bash
python scripts/package_plugin.py --plugin wecom-notify
```

产物输出到 `dist/`（单文件版 + 压缩包），同时打印 SHA-256 与字节数。

## 十一、安全与隐私

- Secret、EncodingAESKey、OpenAPI 令牌**不会**出现在运行日志、返回值与结果页中，仅显示「已填写（长度 N）」；企业 ID 与成员 ID 做掩码处理。
- 插件设置以**明文 JSON** 保存在服务器的插件目录，管理员可读取；更在意安全时请把「应用 Secret」留空，改用环境变量 `TGTO_WECOM_CORP_SECRET`。
- 唯一的写操作是插件数据目录下的 `token.json`（access_token 缓存）与 `history.json`（发送历史），**不写插件源码目录**。
- 不读取与需求无关的任何配置或凭据。

---

## 十二、实现与协议说明

- `access_token` 按「代理地址 + 企业 ID」缓存，提前 300 秒视为过期，避免频繁调用 `gettoken` 被限流。
- 命中 token 失效类错误（`40014` / `41001` / `42001`）时自动清缓存重取并重试**一次**。
- 分段时按行边界切分并逐字符累计字节数，不会切断 UTF-8 字符。
- 插件为同步 `run(params, context)`，不含异步、不含常驻线程；所有网络请求都在 `run` 内发起。
- 仅写入 `context["data_dir"]`，不触碰 `plugin_dir`。
